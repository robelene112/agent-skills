# Personal instructions

`~/.agents/skills/global-communication/SKILL.md`. These communication preferences
apply across machines and task domains.

During work, proactively notice worthwhile updates to tools, container images,
dependencies and operating-system packages. For software or environment work,
read and apply `~/.agents/skills/proactive-updates/SKILL.md`.

For software development, also read and apply
`~/.agents/skills/github-issues/SKILL.md`. Project documentation identifies the
repository, business domain and technical constraints.
