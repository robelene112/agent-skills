# Personal instructions

At the start of every task, read and apply
`~/.agents/skills/global-communication/SKILL.md`. These communication preferences
apply across machines and task domains.

At the start of each session, and during software or environment work, read and
apply `~/.agents/skills/proactive-updates/SKILL.md`. Synchronize the shared skills
source at startup as described there, and proactively notice worthwhile updates
to relevant Git repositories, tools, container images, dependencies and
operating-system packages during work.

For software development, also read and apply
`~/.agents/skills/github-issues/SKILL.md` and
`~/.agents/skills/development-preferences/SKILL.md`. Project documentation
identifies the repository, business domain and technical constraints.
